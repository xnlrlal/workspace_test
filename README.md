# 시그널 — 주가 예측 대시보드

과거 시세 데이터를 기반으로 국내/해외 주식의 단기 추세를 시각화하고,
ARIMA 통계 모델로 향후 가격 범위를 추정해 보여주는 Flask 웹 대시보드입니다.

> ⚠️ **이 도구는 투자 자문이 아닙니다.** 예측치는 과거 가격의 통계적 패턴을 추정한
> 참고 자료일 뿐이며, 실제 주가는 뉴스·수급·거시경제 등 통계 모델이 반영하지 못하는
> 요인에 크게 좌우됩니다. 투자 판단과 책임은 본인에게 있습니다.

## 주요 기능

- **국내 + 해외 통합 조회**: 6자리 코드(예: `005930`)를 입력하면 국내(KRX), 그 외
  티커(예: `AAPL`)는 해외(Yahoo Finance)로 자동 판별하여 조회합니다.
- **기술적 지표**: 이동평균(SMA20/60), RSI(14), MACD, 볼린저밴드를 계산해 캔들스틱
  차트 위에 오버레이합니다.
- **ARIMA 기반 예측**: 종가를 로그 변환한 뒤 AIC 기준으로 최적 (p,d,q) 조합을 탐색해
  적합시키고, 향후 5~90거래일의 예측 평균과 80% 신뢰구간("예측 팬")을 함께 보여줍니다.
- **인터랙티브 차트**: Plotly.js 기반으로 확대/축소, 호버 툴팁을 지원합니다.
- **워치리스트**: 종목 조회 후 헤더의 ☆ 버튼으로 관심종목을 추가/삭제할 수 있으며,
  브라우저 로컬스토리지에 저장되어 새로고침 후에도 유지됩니다.

## 시작하기

```bash
# 1. 가상환경 생성 (권장)
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# 2. 의존성 설치
pip install -r requirements.txt

# 3. 서버 실행
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속하면 대시보드가 열립니다.

> 국내 시세는 FinanceDataReader(KRX 소스), 해외 시세는 yfinance(Yahoo Finance)를
> 통해 실시간으로 조회하므로, 앱을 실행하는 환경에서 해당 사이트로의 인터넷 접속이
> 가능해야 합니다.

## 프로젝트 구조

```
stock_predictor/
├── app.py                   # Flask 앱 진입점 + /api/stock/<ticker> 라우트
├── requirements.txt
├── services/
│   ├── data_fetcher.py      # 국내/해외 시세 조회 (FDR / yfinance)
│   └── predictor.py         # 기술적 지표 계산 + ARIMA 예측
├── templates/
│   └── index.html           # 대시보드 페이지
└── static/
    ├── css/style.css        # 다크 테마 디자인
    └── js/main.js           # 차트 렌더링 & API 연동
```

## API

`GET /api/stock/<ticker>?days=365&horizon=30`

| 파라미터 | 설명 | 기본값 | 범위 |
|---|---|---|---|
| `days` | 조회할 과거 데이터 일수 | 365 | - |
| `horizon` | 예측할 미래 거래일 수 | 30 | 5~90 |

응답에는 `history`(OHLCV + 지표)와 `forecast`(예측 평균·상한·하한·ARIMA 차수)가
포함됩니다.

## 다음 단계로 고려해볼 만한 것들

- **모델 고도화**: ARIMA는 가볍고 해석 가능하지만, 데이터가 충분히 쌓이면
  Prophet이나 LSTM 같은 모델을 옵션으로 추가해 비교해볼 수 있습니다.
- **백테스트**: 예측이 과거 시점 기준으로 실제 얼마나 맞았는지 검증하는 백테스트
  페이지를 추가하면 모델 신뢰도를 가늠하는 데 도움이 됩니다.
